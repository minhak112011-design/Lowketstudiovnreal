# LOWKEY STUDIO

Web shop dịch vụ Minecraft Config + Làm Web.

## Chạy local
```bash
npm install
npm run dev
```

## Deploy Vercel
- Import GitHub repo vào Vercel
- Framework: Vite
- Build command: `npm run build`
- Output: `dist`

## Lưu ý
Bản này lưu dữ liệu bằng localStorage, phù hợp demo/frontend. Muốn web thật nhiều người dùng chung cần backend + database.
